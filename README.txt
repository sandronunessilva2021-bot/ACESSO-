# GUIA FILMES - GitHub Pages

## Arquivos
- index.html: catálogo inicial, categorias, pesquisa e paginação
- filme.html: página individual por ID
- categoria.html: catálogo filtrado por categoria
- busca.html: resultados da pesquisa
- contato.html: página de contato
- style.css: visual responsivo
- script.js: dados e funcionamento

## Instalação
Envie todos os arquivos para a mesma pasta do repositório GitHub Pages.

## Links
Os botões do topo usam:
- Área do cliente: https://clientefinal.com/

## Adicionar filme
Edite o array `movies` em script.js e adicione um objeto com ID único.
Use somente imagens e vídeos que você tenha autorização para disponibilizar.
